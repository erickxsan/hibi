Campo de búsqueda con lupa, para filtrar listas de alumnos, grupos y registros.

**Código:** `SearchInput` en `src/components/ui.jsx`, clase `.search-control`; también `.community-search` y `.tracking-search`.

**El consumidor aporta:** `value`, `onChange` y un placeholder que diga qué se busca («Buscar alumnos o grupos»). La etiqueta «Buscar» queda oculta para lectores de pantalla.

**No hacer:** un botón «Buscar» al lado; el filtrado es inmediato.
